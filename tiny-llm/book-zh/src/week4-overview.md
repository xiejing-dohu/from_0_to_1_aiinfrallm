## 你会构建什么

第4周的目标代理人可以:

- 检查一个存储器,而不将每个文件装入提示;
- 阅读受约束的UTF-8文件,并进行准确、可审查的编辑;
- 执行范围狭小的测试命令并将其输出作为反馈;
- 继续进行互动对话,并在进程退出后恢复对话;
- 重复使用兼容的KV-cache状态,而不是从零开始预先填充;
- 在保持任务状态的同时将上下文压缩;
- 检查站和撤销自己的档案;
- 接受指导信息,中断长期工作;
- 解决通过搁置申报检查分级的小型惰性存储器任务。

这是一个故意的小目标。 具有多种代理代表团等特点,
远程执行、MCP集成和长期用户内存仍为扩展
而不是先决条件。

## 当前可执行基线

检查的参考执行情况比这个目标要小。 这个
目前规定:

- 无国籍者 `generate_response()` 适配器和可重复使用 `GenerationSession`;
- 严格分析最后答案或结构化工具行动;
- `list_files`, `read_file`, `write_file`, `edit_file`,以及 `run_command`;
- 默认情况下只读工作空间工具,有明确的工具授权和
  (a) 逐一发出的通知批准;
- 持久附加的会话记录、恢复和项目指示快照;
- 预算编制、有限度观察和持久的结构化
  压缩;
- 一个合作取消信号 跨环,课程模型解码,
  存档,并指挥投票;
- 持久的引导信息、写头文件更改意图、启动
  和解、分支-地方检查站、默认-无撤销计划以及会话
  分支;
- 密封的惰性任务包、冻结候选人的快照、确定性静态
  检查、禁用路径检测和评价标准;
- 记录行动、观察、确认和
  结果- 不确定的文件工具修改, 命令是否可能
  未跟踪或未完全清理的副作用,及其终极原因.

`AgentRun.completed` 记录协议的补全—— 来自
模型 - 任务正确。 第七天把球场和静态分开
年级 `GradeReport` 和 `EvaluatedRun.task_success`。检查点,撤销,分支,
指导支持是第6天的API,而不是互动的CLI
命令。 主CLI记录中断运行和有状态130的退出
在Ctrl -C之后。 。

## 核心循环

每个章节都建立在同一个循环上:

1. 提出任务、项目指示、最近的事件和工具说明。
2. Decode 一种结构化行动,使用该模式 KV cache.
3. 在动作到达操作系统前,分析并验证动作.
4. 对于写作,编辑,或命令,获得新的默认-无人批准.
5. 运行已核准的工作空间工具并将其观测结果附在会话中。
6. 重复,直至模型返回最后答案或达到预算。

该模型不直接编辑文件 。 它提出一个行动;普通代码
决定这一行动是否有效并付诸实施。 这个边界是代理
行为容易检查和测试。

```text
task + session events
        |
        v
  context builder ---> model ---> action validator
        ^                            |
        |                            v
   tool result <--- tool runner <--- policy + conditional y/N gate
                         |
                         v
                      workspace
```

## 状态推理扩展

开始的模型边界是故意无国籍的:

```python
Generate = Callable[[list[Message]], str]
```

对于每一个行动, `generate_response()` 让整个谈话,
为每个模型层创建新缓存, 预先填充整个提示, 解码
一个响应,然后释放缓存。 这是一个有用的正确性基准,
但交互式代理多次发送长的提示,其前缀勉强
变化。

第4天增加一个可调用
`GenerationSession` 保持同样的代理 API 拥有时 token 身份证
和层缓存。 它比较了新变速器和缓存器 token
顺序,倒转一个不同的后缀,并只预填新符号。 第5天
和 6 在压缩、引导和会话分支后再使用此操作。

仅附件事件日志仍然是
事实 一个进程重新启动可以从事件重建 KV 状态, 因此持续 K/ V 到
磁盘是一种可选的优化,而不是正确的要求.

Qune3-4B背景预算为32,768个总代币. 第5天开始
压缩为24 576个输入符,并保留其余8 192个输入符。
下一个响应和工具输出。 这个限制跟随模型的训练范围,
没有可用的统一内存数量; 衍生和长文
测量值在
[业绩附录](./appendix-performance.md#long-context-budget-for-week-4).

## 一个小工具表面

基线使用由小编码剂牵引物启发的五个工具. 这些
名称和字段是可执行 JSON 协议 :

```text
list_files(path?)
read_file(path)
edit_file(path, old, new)
write_file(path, content)
run_command(argv)
```

`read_file` 和 `edit_file` 比壳等效物更好,因为它们可以
执行一致的界限并返回结构错误。 `list_files` 提供
定界发现. `run_command` 接受非空 JSON 阵列的精确
参数, 无 shell 运行, 并使用工作空间配置的超时
;该模式不能提供自己的超时。

操作员必须首先启用写入或命名一个精确允许的命令 。 这是
只有外政策门 合格模型分发后 `write_file`,
`edit_file`,或 `run_command` 行动通过计划、政策和工具飞行前,
CLI请求 `y/N`; 空响应、 EOF、 非交互输入或任何
除了明确回答是以外,还拒绝电话。 文件突变然后重新验证
他们的路径 和观察的文摘 在承诺之前。 拒绝还给模特儿
作为观察.

贝壳工作目录不是安全沙盒. 在此期间,运行
仅在一次性运动工作空间进行代理。 生产代理商需要
容器,虚拟机,或类似的强隔离边界. 准确
允许命令仍然可以删除文件, 在工作空间外读取, 启动子
进程,或使用网络。 人类确认减少意外处决;
它并不限制核准的方案。

因此,第7天在评价期间禁用命令,绝不进口或
执行候选代码。 其搁置的检查解析了约束文本,JSON,和
Python AST通过一个冷冻的快照。 这是一个诚实的静态检查站,不是
一般行为码评价员. 参选候选人 Python,pytest,编译器,
或任务本地分级器被推迟到容器或虚拟机后端。

第6天在每个日记文件替换前添加写头意图. 重新启动时
日记将当前内容和模式指纹与记录的指纹进行比较
和打算提交的国家和记录 `committed`, `not_applied`,或 `conflict`
不更改文件。 检查点撤消一个完整的计划冲突
并保持默认-否。 从替换或
撤销时不得使用工具,并报告进行人工检查。 命令为
在可逆文件日记之外, 从未被声称为不可撤销 。

默认演示现在将课程模型调用到 `GenerationSession`; 数据
`--solution mlx` 兼容后端保留无国籍适配器. 经纪人
循环、工具和安全工作仍然是主要弧,而互动会议
在不改变模型内核的情况下提供重点推理-框架练习.

## 运行开始演示

存储库包含一个使用参考模型的最小演示
执行:

```bash
pdm run agent "inspect this project and summarize its files"
```

过 `--solution tiny_llm` 利用您的执行,或 `--solution mlx` 改为
使用 MLX-LM 的优化执行器. 启动程序故意较小
而非最终代理:每天用一个明确的组件替换一个快捷键
可以进行检查和测试。

当前命令的工作空间工具是只读的,没有显示命令运行符
默认。 除非我们... `--no-session` 选择时, CLI 仍然写着它的敏感
当地记录 `.tiny-llm/sessions`.
`--allow-writes` 并重复 `--allow-command "..."` 旗帜制作这些工具
符合资格。 每个通过飞行前的合格动作仍然默认为 **没有** 时间
联合国 `y/N` е翴 保留 `--root` 指向可支配练习目录。 这样做
不解释精确的命令许可列表、工作目录或确认
提示为进程隔离。

4日CLI支持时 `--interactive`, `--continue`, `--session`,以及
`--no-session`。持续记录誊本是当地敏感文件,属于
`.tiny-llm/sessions`; `--no-session` 保留早期的麻风行为。
代理运行时的 Ctrl- C 记录持续会话时的中断
使用、报告已知副作用和130状态出口。 第6天检查站,
取消、分支和现场操作是锻炼利用的API;
CLI还没有给他们下达命令。

第7天检查CLI不会加载模型或变异候选人. 这可以
用静态分级器验证包元数据并分级一个不变的定格 :

```bash
pdm run evaluate-agent inspect evals/week4/localized-constant
pdm run evaluate-agent grade evals/week4/localized-constant
```

等级命令使用新的临时舞台和冷冻快照. 总是这样
命令已禁用, 提供不自动写入批准, 并且从未运行代码
从包裹。 发运的不变固定装置故意不正确:
`inspect` 退出为零,而 `grade` 打印普通失败的报表并退出其中。

默认 Qwen3 4B模型更可靠地遵循结构化的动作协议.
使用 `--model qwen3-0.6b` 在内存受限制的机器上 并期望花费更多
行动失常恢复的时间。

## 目标里程碑

- **最小值 :** 该模型可以检查一个工作空间并产生一个有效的动作。
- **有用吗 :** 代理人可以做出精确的改变并进行测试。
- **可回收 :** 会议可以恢复、压缩和取消自己的变化。
- **可控 :** 预算约束,用户可以指导或中断工作。
- **高效 :** 兼容性转换为再使用其未变换的提示前缀。
- **可测量:** 可重复的任务套件可以区分进度和轶事。
