# 学习 LLM 推理服务

这个课程是为系统工程师设计的,他们想了解大语言模型(LLM)是如何工作的.

作为一个系统工程师,我总是好奇 事情是如何在内部运作,如何优化。 我发现这很难
来理解 LLM 推理,因为大多数开源服务项目都与 CUDA 内核和其他项目高度优化
低级技术。 很难在一个有数十万行的密码库里看到整个画面。 因此,我建议
决定执行 LLM 仅使用数组和矩阵操作从头为项目服务。 目标是理解
装满什么 LLM参数和进行生成文本的数学操作。

你可以把这门课程看作 LLM 领域的 [Needle](https://github.com/dlsyscourse/hw1/tree/main/python/needle) 项目，
项目来自CMU的深层学习系统课程.

## 先决条件

你应该了解深层学习的基本原理,熟悉PyTorch. 我们建议提供下列资源:

- 机器学习入门](https://www.cs.cmu.edu/~mgormley/courses/10601/) ——涵盖机器学习的基本原理.
- 深层学习系统](https://dlsyscourse.org) ——教你如何从零开始构建像PyTorch这样的框架.

## 环境设置

本课程使用[MLX](https://github.com/ml-explore/mlx),用于苹果硅的阵列和机器学习框架. 为:
许多学习者,苹果硅设备比NVIDIA更容易访问 GPU原则上,你也可以完成
与 PyTorch 或 NumPy 设置,但测试基础设施不支持它们作为执行后端。 相反,
测试将您的执行与信任相比较 MLX 操作和示范实施以核实正确性。

## 课程结构

这个课程分为四个星期. 我们将服务 Qwen3 MLX 模型,优化服务路径,并利用它构建一个
小编码代理.

- 第1周:服务 Qwen3 使用数组和矩阵操作 Python.
- 第2周:执行定制 C++ 和 Metal 内核加速模型.
- 第3周:增加高通量服务的进一步优化和批量请求。
- 第4周:在本地编码代理中重新使用服务堆栈,并配有工具、会议和评价。

## 如何使用此书

那个 tiny-llm 书是实用指南,而不是从第一原理解释每个概念的教科书. 我们联系
对作者在执行项目时认为有用的资源,而不是重复其解释。
每章提供一系列任务,支持读数,以及执行提示.

该书还使这些资源的术语和标记标准化,以便它们能清晰地映射到编码库。 为:
例如,我们使用一致的符号来表示拉伸维度,并解释 `H`, `L`,以及 `E` 在使用点上意味着。
